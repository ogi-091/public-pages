# public-pages

Public static pages for apps maintained by the repository owner.

Each app gets its own service slug and public path:

```text
site/<service-slug>/privacy-policy/index.html
```

The published URL is:

```text
https://ogi-091.github.io/public-pages/<service-slug>/privacy-policy/
```

Only public-facing documents belong in this repository. Private application source code, internal specifications, credentials, and unpublished operator details must stay in their respective private repositories.
